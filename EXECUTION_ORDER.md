# Zenith OTT — порядок выполнения промтов

Навигатор для следующего чата, где начнётся реализация. Ничего из
содержания промтов не сокращено и не убрано — этот файл только про
**порядок**, чтобы не наткнуться посреди сессии на промт, который
явно требует другого сначала (на бесплатном тарифе это стоит целой
впустую потраченной сессии, не просто неудобство).

Порядок — рекомендация, не жёсткое предписание. Внутри каждой группы
последовательность не важна, между группами — важна, зависимости
объяснены.

---

## Шаг 0 — проверить руками, прежде чем начинать (не промт, а факты)

Без этого шага можно смело работать над всем, кроме `PROMPT_LOCAL_SYNC_V1.md`
(явно указывает на это предусловие внутри себя):

- Задан ли `REDIS_URL` на Render / подключён ли persistent disk
- Логи (`logcat`, `PlaybackException`) при попытке включить Archive.org
- Играет ли серия из тестового плейлиста через 30-40 минут после добавления

## Шаг 6 — Региональные ограничения доступа

- `PROMPT_REGIONAL_ACCESS.md` — ни от чего из списка выше не зависит
  технически, но продолжает незакрытый диагностический вопрос
  ("Archive.org требует VPN", см. `NEXT_STEPS.md`) — реально мешает
  просмотру части контента уже сейчас, поэтому по приоритету это не
  "куда-то в середину", а следующая сессия. Первая сессия — диагностика
  (тест с другой сети) + веб-поиск актуального состояния
  блокировок/инструментов (тема быстро меняется, обучающие данные модели
  могут быть устаревшими) + план, не код.
