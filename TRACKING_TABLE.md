## Сетевые ограничения / региональные блокировки

Продолжение пункта "Archive.org требует VPN" ниже по файлу (раздел
"Сейчас открыто и ждёт вас") — расширено с одного источника на общий
случай по запросу Shadow: не только DNS, любой хост (M3U/Xtream-панель,
`zenith-backend`) может блокироваться регионально (DPI по SNI, TCP-уровень,
не только резолвинг).

| Тема | Статус | Где | Следующий шаг |
|---|---|---|---|
| Archive.org не воспроизводится без VPN — сеть Shadow блокирует archive.org, или archive.org блокирует IP хостинга Render (`zenith-backend`)? Не различено | 🟡 диагноз не завершён | `NEXT_STEPS.md`, `ROADMAP.md` п.2 | нужен тест с другой сети, см. запись ниже |
| **Региональные ограничения доступа в целом** (DNS + DPI/SNI-блокировки + возможность встроенного прокси/VPN-туннеля для трафика приложения, с оглядкой на подход РосКомСвободы — самохостинг, не общий публичный VPN) | 🟢 промт готов (первая сессия — диагностика/веб-поиск актуального состояния блокировок + план, не сразу код) | `PROMPT_REGIONAL_ACCESS.md` | согласовать план подзадач, начиная с реального теста Archive.org с другой сети (см. строку выше) |
