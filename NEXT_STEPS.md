## Этап 1: Проверка на устройстве

### 1.1 Скачать APK

```
GitHub → Actions → последний билд → Artifacts → Zenith-TV-Debug-APK → Download
```

### 1.2 Установить на телефон/TV

```bash
adb install app-debug.apk
```

Или через USB на Android TV:
```bash
adb connect <TV_IP>:5555
adb install app-debug.apk
```

### 1.3 Что проверить

| Экран | Что смотреть | Ожидание |
|---|---|---|
| Setup | Ввод M3U URL | Переход на Home; кнопки «Избранное»/«История»/«Настройки» доступны даже без ввода URL |
| Home | Список фильмов | Карточки с постерами, кнопка/иконка «Поиск» в шапке |
| Search | Ввод названия | Результаты из бэкенда + плейлиста, тап ведёт на Detail |
| Detail | Информация о фильме | Backdrop/постер сверху, описание, кнопка Play |
| Player | Воспроизведение HLS | Видео + контролы (название, play/pause, перемотка, качество — на TV и на телефоне) |
| Favorites | Добавить/удалить | Сохраняется |
| History | Просмотр записи | Добавляется автоматически, с постером (TV и телефон) |
| Settings | Качество/сеть/уведомления | Переключатели реально сохраняются, не декорация |

### 1.4 Известные ограничения (не баги)

- Плагины не тестировались (нет сервера плагинов)
- TMDB может не работать без API ключа
- QR-сканер требует реальную камеру
- Поиск не видит содержимое M3U/Xtream через полноценный API-поиск — только подстрокой по уже загруженному локально списку (у PlaylistRepository нет текстового поиска на сервере)
- «Тихий режим» в уведомлениях настраивается только по целым часам (кнопки −/+), без time-picker'а

## Этап 4: Релизная подготовка

### 4.1 Release keystore — уже настроено

`app/build.gradle.kts` читает `KEYSTORE_BASE64`/`KEY_ALIAS`/`KEY_PASSWORD`/`STORE_PASSWORD`
из переменных окружения (GitHub Secrets), debug.keystore в репозитории — для debug-сборок,
не для релиза.

### 4.2 Создать первый релиз

```
GitHub → Releases → Create new release
Tag: v1.0.0
Title: Zenith OTT v1.0.0
```

CI автоматически соберёт signed APK + AAB.

### 4.3 Подготовить описание

- Скриншоты экранов
- Описание функционала
- Системные требования (Android 8.0+, 2GB RAM)
- Ссылка на APK/AAB
